# CostAllocationPipeline
This project is to help automate the billing for IT departments using the CLoud Infrastructure

## Project board

The delivery plan lives in [docs/kanban](docs/kanban): 40 tickets, each with a description and acceptance criteria.

- [BOARD.md](docs/kanban/BOARD.md): column overview (Backlog, To Do, In Progress, In Review, Done)
- [TICKETS.md](docs/kanban/TICKETS.md): every ticket in full
- [index.html](docs/kanban/index.html): interactive board (open in a browser)
- [tickets.json](docs/kanban/tickets.json): source of truth. After editing it, run `python3 docs/kanban/build_board.py` to regenerate the other files.
